# Model Switch for 畅Work

这是一个仿 CC-Switch 使用思路的 Windows 桌面模型管理器，专门管理畅Work/OpenClaw 的自定义模型提供商。

## 启动

直接双击真正的 Windows 桌面程序：

```text
ModelSwitch.exe
```

不再依赖 PowerShell 脚本、执行策略或命令窗口。若从 ZIP 下载，请先完整解压后再运行，不要直接在压缩包预览窗口中启动。

应用默认读取：

```text
%USERPROFILE%\.cclaw-assist\cclaw-assist.json
```

## 主要功能

- 卡片式浏览全部自定义提供商
- 新增、编辑和删除提供商
- 支持多个 API 协议适配器
- 一个提供商可配置多个模型
- API Key 粘贴后点「保存」即可，直接写入本地配置，无需配置环境变量
- 点击“获取上游模型”，自动请求 `Base URL/models`
- 支持 OpenAI 风格 `data[].id`、`models[].id` 和字符串数组返回格式
- 上游新增模型先在搜索/勾选窗口中选择，再加入本地列表
- 上游已下线、不再返回的模型会从当前提供商列表移除
- 移除前显示差异并二次确认，最后仍需点击“保存”才会写入配置
- 若下线模型正被 Agent 设为默认模型，会弹出醒目警告
- 按 Agent 查看当前默认模型
- 双击选择模型并一键启用
- 每次写配置前自动备份
- 浏览并恢复历史备份
- 导入/导出提供商配置，方便迁移到其他电脑
- 保存时保留频道、插件、MCP 等无关配置
- 本机存在 `openclaw` 命令时，修改正式配置后自动执行 schema 校验；失败自动回滚

## 快速上手（新增第三方模型）

1. 点「＋ 新增提供商」，填写提供商 ID（小写字母开头，可含数字、下划线、连字符）。
2. 选择 API 适配器（大多数 OpenAI 兼容中转站选 `openai-completions`），填写 `Base URL`。
3. 在 `API Key` 输入框粘贴服务商提供的密钥。
4. 点「获取上游模型」自动拉取模型目录，勾选需要的模型；也可以点「＋ 添加模型」手动填写。
5. 点「保存」。
6. 在模型列表中选中要用的模型，点「启用选中模型」。
7. 完全退出畅Work（包括托盘进程）后重新启动。

## 模型列表格式

每行一个模型：

```text
模型ID|显示名|上下文窗口|maxTokens|reasoning
```

例如：

```text
gpt-5.6|GPT 5.6|200000|32000|true
gpt-5.6-mini|GPT 5.6 Mini|128000|16000|false
```

只有模型 ID 是必填项。

## 获取上游模型

1. 选择或新增一个提供商。
2. 填写 `Base URL` 和 API Key。
3. 点击模型列表右上角的“获取上游模型”。
4. 程序会请求 `Base URL/models`；如果 Base URL 本身已经以 `/models` 结尾，则直接使用。
5. 程序将本地列表与上游列表进行对比：
   - 已存在的模型保留原来的显示名、上下文窗口、maxTokens 和 reasoning 参数；
   - 上游新增模型进入勾选窗口，可选择需要导入的模型；
   - 上游不再返回的模型列入待移除清单，确认后从界面列表移除。
6. 检查状态栏中的新增、移除数量。
7. 点击主界面的“保存”，同步结果才会写入配置。

为了避免接口异常导致误删，只有在接口成功返回并识别到至少一个模型时才执行差异同步；失败、空列表或取消确认都不会修改本地列表。OpenAI 风格接口使用 `Authorization: Bearer <API_KEY>`；Anthropic 适配器使用 `x-api-key`。

## 从旧工具升级

新版交付为单文件桌面程序：

- `ModelSwitch.exe`：直接双击启动的 Windows 图形化应用

旧版中通过环境变量保存的密钥仍然兼容：工具会自动读取对应环境变量的值用于验证和同步。重新粘贴密钥并保存后，会改为直接写入配置，不再依赖环境变量。

开发源文件仍保留在任务目录中，但普通使用不需要 PowerShell，也不需要安装 Node.js、Python 或 .NET SDK。

## 迁移到新电脑

推荐流程：

1. 在旧电脑打开“备份与迁移”。
2. 点击“导出提供商配置”。
3. 把工具文件夹和导出的 JSON 复制到新电脑。
4. 新电脑安装并启动一次畅Work。
5. 启动 Model Switch，导入 JSON。
6. 若提示缺少密钥（例如旧配置使用环境变量引用），打开对应提供商，粘贴新电脑可用的 API Key 并点击“保存”。
7. 为 `main` Agent 启用默认模型。
8. 完全退出畅Work（包括托盘进程）后重新启动，使新配置生效。

## 认证失败排查

若提示 `Invalid token` 或“模型服务认证失败”：

1. 在 Model Switch 中选择出错的提供商。
2. 确认 Base URL 和 API 适配器与服务商要求一致。
3. 在 `API Key` 输入框粘贴该服务商提供的有效密钥（注意不是其他平台的密钥，也不要填占位文本）。
4. 点击“保存”。
5. 点击“获取上游模型”验证认证；成功列出模型说明密钥有效。
6. 完全退出畅Work及托盘进程，再重新启动。

## 安全说明

- API Key 以明文保存在本机配置文件 `%USERPROFILE%\.cclaw-assist\cclaw-assist.json` 中，自动备份与导出文件同样包含密钥。
- 请勿把配置文件、备份文件或导出文件公开上传、发送到群聊或交给无关人员。
- 恢复备份前，工具仍会自动保存当前配置的安全快照。

## 界面适配

界面采用响应式布局，窗口缩放或 Windows DPI 放大时，提供商字段、API Key、模型列表和底部操作按钮会自动重新分配宽度。
